# 前端组件语法教学与智能测试系统

一个零依赖、离线运行的前端语法教学软件：内置一套自主编写的迷你 Vue2 仿真内核，
把"数据变化为什么能带动界面更新"的内部过程完整暴露在课堂上。

> 本软件不是 Vue 官方库，仅供教学演示与上机实训使用，请勿用于生产项目。

## 功能一览

- **模拟实验**（index.html）：7 组共 26 个可运行教学案例，覆盖插值与表达式、指令、事件与绑定、计算属性与侦听器、组件化、生命周期、实例方法；案例源码可就地修改，右侧手机框实时预览，控制台输出运行结果与报错原因。
- **知识点测试**（test.html）：在完整代码中挖出若干空位，学生逐空补全后点击判分；按空位逐一比对（忽略空白差异），并把补全后的代码真实运行，"判分结果"与"能否运行"互相印证；成绩按登录账号分桶保存，可一键导出 CSV 成绩表。
- **教师出题**（new-quiz.html）：粘贴任意一份可运行的组件源码，选中文字即可挖空并录入答案，工具自动校验并导出为 `.json` 题目文件，替换题库文件即完成升级。
- **登录守卫**：账号（6–20 字符）、姓名、手机号三项校验加核对弹窗；退出登录不影响已保存的成绩。

## 快速开始

1. 下载或克隆本仓库；
2. 双击 `login.html`（推荐 Chrome / Edge 较新版本）；
3. 填写账号、姓名、手机号，核对无误后进入主界面。

无需安装、无需联网、无需管理员权限，拷贝整个目录即可在断网机房运行。

## 目录结构

```
login.html         登录页
index.html         模拟实验主界面
test.html          知识点测试
new-quiz.html      教师出题工具
js/                仿真内核与应用脚本
js/knowledge.json  案例档案（用新文件覆盖即升级）
js/quiz.json       题库档案（用新文件覆盖即升级）
```

## 内核能力边界

支持常用语法子集：文本插值、`v-text` / `v-html`、`v-if` / `v-else-if` / `v-else` / `v-show`、
`v-for` 数组遍历、`v-model`（文本框、单选、复选、复选框组、下拉框）、`:class` / `:style` 等属性绑定、
`@click` 等事件绑定、`computed`（含 get / set）、`watch`（deep / immediate）、
局部组件与 `props`、`created` / `mounted` 钩子、`this.$set` 与 `this.$nextTick`。

不支持插槽、`$emit` 自定义事件、事件修饰符、过滤器等进阶特性。教学时请向学生明确：
这是一个面向课堂的仿真子集，与真实框架在边界之外的行为可能不同。

## 环境要求

现代图形化浏览器即可，唯一存储依赖是 localStorage（保存登录信息与成绩）。
若机房策略禁用本地存储，页面会给出明确提示，成绩仅当次有效。
